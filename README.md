RPGHelper project:

Project is for an app to help Dungeon Masters of Roleplaying games be able to quickly select random treasure, random NPCs, random stronghold additions or random 8 bit type maps if needed for players. Aim to have the ability to favorite certain stronghold additions, random NPCs or random maps and have the data stored locally. Also aim to have a database of magical items the Dungeon Master can also get a pseudorandom selection of 1 item at a time if needed by players.
